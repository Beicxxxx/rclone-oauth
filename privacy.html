Privacy policy

rclone-oauth is a personal OAuth client. Its only user is its owner, GitHub user Beicxxxx.

  • It accesses Google Drive with the drive.file scope only, which limits it to files that it created.
  • Data moves only between the owner's own machines and the owner's own Google Drive. Nothing is collected, sold, shared with third parties, or used for advertising or model training.
  • OAuth tokens are stored only in the owner's own secret store and machines.
  • The owner can revoke access at any time at myaccount.google.com/permissions.

Questions: open an issue in the rclone-oauth repository.
